# Эксперименты

Цель — проверить одну эргономическую или игровую гипотезу на минимальной сцене. Автотесты проверяют корректность механики, удобство оценивается вручную.

## Порядок сравнения

1. Зафиксировать исходный тег, ветку, набор параметров, размер окна и масштаб браузера.
2. Вернуть игровые параметры по умолчанию и нажать «В начало».
3. Для движения отключить спавнеры; для боя задать одинаковые интервалы и лимит.
4. Изменять один фактор за раз. Повторить одинаковую последовательность команд в обоих вариантах.
5. Записать ошибки управления, остановки, случайные атаки, читаемость замаха и FPS. Субъективную оценку отделять от измерений.

## Базовые сцены

- **Движение:** клик в четырёх направлениях, удержание неподвижного курсора, разворот на 180°, остановка у героя.
- **Выбор атаки:** клик по мишени, наведение при удержании, сближение с курсором в стороне. Проверить все три режима.
- **Продолжение:** отпустить кнопку после захвата, затем дать команду по земле. Проверить включённое и выключенное автопродолжение.
- **Ответ на урон:** включить ответ, дождаться попадания свободному герою; повторить во время движения и атаки другой цели.
- **Толпа:** одинаковый интервал и лимит спавна, движение между живыми кругами, атака после заблокированного движения.
- **Смерть:** убить цель, пройти через останки, сбросить мир; отдельно проверить смерть героя.
- **Прерывание:** меню во время удержания и замаха, потеря фокуса, возврат к игре без нового нажатия.

Хранить заполненные записи в `docs/experiments/` вместе с соответствующей веткой. Большие видео и автоматические снимки не коммитить; ссылку на отдельно сохранённый материал добавлять только при необходимости.
