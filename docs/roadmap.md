# Следующие исследования

Это список направлений для отдельных вариаций, а не обещание реализации.

| Направление | Проверяемый вопрос |
| --- | --- |
| Статические препятствия и обход | Как автоподход сообщает о недоступной цели и выбирает путь? |
| Дистанция от границы круга | Понятнее ли дальность атаки от края тела, чем между центрами? |
| Ускорение и разворот | Какие значения дают точное управление без ощущения мгновенного скольжения? |
| Выбор и удержание цели | Как триггер захвата влияет на случайные атаки и доступность движения? |
| Продолжение и ответ на урон | Когда автоматизация помогает, а когда отнимает контроль? |
| Слои и нокдаун | Достаточны ли масштаб и слой для читаемого состояния без анимации тела? |
| Длительная сессия | Как накопление останков и увеличение толпы влияют на FPS и стоимость шага? |

Текущие ограничения: нет поиска пути, статических препятствий, сохранения прогресса, инвентаря, добычи, уровней, звука и удаления останков. Спавн идёт по очереди с четырёх сторон, не одновременно. Мишень неподвижна и не атакует. Смерть героя требует «В начало».

Следующий вариант выбирать по одной гипотезе и сравнивать с `v0.1.0` по одинаковому сценарию.
