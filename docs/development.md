# Разработка и вариации

## Подготовка

Требуются Git и Node.js 22+. Для игры достаточно `start-local.bat` или `npm start`. Для разработки:

```powershell
npm ci
npx playwright install chromium
npm test
```

Unit-тесты запускаются через `npm run test:unit`, браузерные — через `npm run test:browser`. Chromium-тесты используют отдельный сервер на порту 4174; обычная игра — 4180. Перед браузерными тестами освободить 4174. Не запускать несколько наборов браузерных тестов одновременно.

После изменения сервер отдаёт новые файлы без сборки; обновить вкладку браузера. Нельзя открывать `index.html` через `file://`.

## Основа для вариаций

Тег `v0.1.0` фиксирует текущий прототип. `main` хранит общую линию разработки. Каждую независимую вариацию начинать отдельной веткой от тега:

```powershell
git switch -c experiment/attack-input v0.1.0
```

Название после `experiment/` отражает гипотезу. Перед переключением сохранить свои изменения коммитом. Не менять тег базовой версии и не перезаписывать опубликованную историю.

Для одновременной работы с вариантами:

```powershell
git worktree add ../ARPG-camera -b experiment/camera v0.1.0
```

В новом каталоге отдельно выполнить `npm ci`, если нужны тесты. Для одновременного запуска использовать разные порты: `start-local.bat 4181`. У разных портов отдельные настройки браузера. Для последовательного сравнения на одном порту перед каждым вариантом вернуть параметры по умолчанию.

## Изменения

Добавлять параметры в `PARAM_SCHEMA` и `DEFAULT_PARAMS`; меню и кнопки сброса строятся автоматически. Не дублировать числовые значения в UI. Для изменений симуляции предпочтительны проверки её наблюдаемого поведения. Для мыши, паузы, сохранения и меню нужны браузерные сценарии.

Проект использует OpenSpec. CLI нужен только для работы с требованиями, игра и тесты от него не зависят. Существующий установленный CLI:

```powershell
openspec list --json
openspec validate --all --strict
```

Поведенческие изменения описывать в отдельном change с proposal, design, specs и tasks; использовать проектные навыки в `.agents/skills/`. Выполненные изменения не архивировать автоматически: синхронизация и архивирование — отдельный шаг.

Перед завершением вариации обновить документацию, выполнить подходящие тесты и записать эксперимент по [шаблону](experiments.md). В репозиторий не включаются зависимости, отчёты Playwright, снимки и локальные секреты.
