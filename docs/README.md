# Документация

Текущая основа: `v0.1.0`, 6 октября 2026 года. Это лаборатория управления и боя, а не законченная ARPG.

- [Запуск, управление и параметры](../README.md).
- [Архитектура](architecture.md): модули, игровой цикл, координаты, атака и сохранение.
- [Разработка и вариации](development.md): подготовка среды, проверки, ветки и базовая версия.
- [Эксперименты](experiments.md): сравнение вариантов и шаблон записи результатов.
- [План следующих исследований](roadmap.md).
- [История версии](../CHANGELOG.md).
- [Правила изменений](../CONTRIBUTING.md).
- [Проверка текущей основы](baseline-verification.md).

`verification.md`, `combat-verification.md` и `auto-engage-verification.md` — исторические отчёты ранних этапов. Их количество тестов и состав стартовых объектов относятся к соответствующему этапу.

`openspec/specs/` содержит ранее синхронизированные требования. Последующие завершённые изменения находятся в `openspec/changes/`; они ещё не архивированы. Для поведения текущей версии использовать README, исходники и более поздние изменения. Не считать старые требования о стартовом неподвижном враге актуальными.
