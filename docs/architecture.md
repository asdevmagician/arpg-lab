# Архитектура

Приложение работает локально в браузере. Canvas 2D рисует мир; DOM обслуживает меню. В игровом коде нет сторонних библиотек, внешних запросов и сборки. Node.js нужен для локального HTTP-сервера и тестов.

## Модули

| Файл | Ответственность |
| --- | --- |
| `src/main.js` | Canvas, мышь, захват указателя, размер окна, пауза, кадры и интерфейс статуса |
| `src/simulation.js` | Состояние мира, движение, команды, бой, ИИ и спавн |
| `src/collisions.js` | Проверка пути круглого тела, скольжение и устранение пересечений |
| `src/settings.js` | Значения по умолчанию, схема параметров, проверка и localStorage |
| `src/ui.js` | Разделы настроек, связанные поля, индивидуальный и общий сброс |
| `src/render.js` | Подложка, портреты, кольца HP, следы оружия и отладочные коллайдеры |
| `src/layers.js` | Порядок слоёв и масштаб живых объектов и останков |
| `src/fps.js` | Частота отрисовки по временным меткам кадров |
| `scripts/server.js` | Сервер на loopback, выдача HTML/CSS/JS/SVG и запуск браузера |

## Цикл и координаты

`requestAnimationFrame` задаёт отрисовку. Симуляция накапливает время и выполняет фиксированные шаги по 1/120 секунды. Длинный кадр ограничивается 0,1 секунды; пауза сбрасывает накопитель. FPS измеряет кадры браузера, а не шаги симуляции.

Мировые координаты бесконечны в обе стороны. Камера совпадает с координатами героя. Масштаб камеры преобразует мировые единицы в экранные; DPR увеличивает разрешение Canvas, сохраняя размеры интерфейса. Сетка и декор привязаны к миру.

## Состояние и команды

Герой хранит позицию и скорость отдельно от здоровья. `enemy` — учебная мишень в (220, 0); `spawnedEnemies` — единственный список атакующих скелетов. При запуске и сбросе он пуст. Спавнер циклически использует верхнюю, правую, нижнюю и левую стороны текущей камеры. Лимит считает только живых скелетов.

Клик по земле задаёт мировую цель. Удержание после порога переводит команду в следование. Клик по живой цели запускает автоподход. Режим автоперехода может захватить цель при наведении или сближении. Автопродолжение сохраняет повторные атаки после отпускания; новая команда движения отменяет их. Ответ на урон выбирает ударившего врага только когда герой свободен.

## Бой и коллизии

Фазы героя: `idle`, `approach`, `windup`, `swing`, `recovery`. Параметры удара фиксируются в начале замаха. Урон наносится один раз в середине удара после повторной проверки расстояния между центрами. Дуги чередуют направление. Скелет преследует героя и останавливается во время фаз атаки.

Живые тела имеют общий настраиваемый круглый физический радиус. Проверка всего пути предотвращает проход сквозь круг при быстром движении; наклонный контакт сохраняет скольжение. Поиска обходного пути нет. Если дальность атаки меньше суммы радиусов, контакт с целью не позволяет войти в дальность.

При 0 HP объект перестаёт быть целью и препятствием, переходит на слой −1, теряет кольцо здоровья и цвет и уменьшается. Герой рисуется последним среди объектов одинакового слоя. Масштаб портрета не меняет физический радиус.

## Пауза и сохранение

Открытие меню, потеря фокуса и скрытие вкладки приостанавливают симуляцию и прерывают ввод. Возврат не воспроизводит пропущенное время. Меню оставляет отрисовку и FPS активными.

`arpg-lab-parameters-v1` хранит параметры; `arpg-lab-interface-v2` — видимость меню и состояние разделов. Здоровье и прогресс мира не сохраняются. Проверка данных ограничивает диапазоны и восстанавливает отсутствующие поля. Отказ хранилища не мешает текущей сессии. Параметры относятся к origin: смена порта создаёт отдельное сохранение.

С `?test=1` доступен только читаемый снимок состояния `window.__arpg.snapshot()` и проверка готовности портретов. В обычной игре тестового интерфейса нет.
