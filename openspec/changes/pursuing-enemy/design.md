# Design

## Context

См. предложение и спецификацию pursuing-enemy. Симуляция уже содержит независимые фазы боя скелета, общий выбор целей и слои смерти; фиксированный шаг и пауза управляются основным циклом.

## Goals / Non-Goals

**Goals:** добавить движение одного противника, сохранив прежние актёры и формат снимка состояния.

**Non-Goals:** препятствия, поиск пути, инерция врага, радиус обнаружения и новые изображения.

## Decisions

- Добавить `state.pursuer` с отдельным `combat`, общими полями здоровья и слоя. Включить его в `getEnemies`, выбор и отрисовку с существующим skeleton.svg. Перенос всех актёров в массив потребовал бы менять существующие обращения без пользы для этого эксперимента.
- Вычислять начальную позицию при create/reset: `x = viewport.width / (2 * cameraZoom) + 240`, `y = 0`. После начального fit сбросить мир, чтобы использовать настоящий размер Canvas. Последующие resize и зум меняют только камеру, сохраняя мировую позицию врага.
- Обобщить существующий цикл атаки скелета для двух противников. Преследователь в idle идёт по нормированному направлению к герою со скоростью `enemyMoveSpeed`, ограничивая шаг расстоянием до `enemyAttackRange - 2`. Во всех фазах атаки стоит. После восстановления снова оценивает актуальную позицию героя. Готовые тайминги и перепроверка дистанции сохраняются.
- Новый параметр скорости: 110 ед/с, 0–400, шаг 10, группа «Враг». Ноль останавливает преследование, но оставляет атаки в пределах дистанции. Хранилище совместимо с прежними записями.

## Risks / Trade-offs

- Два врага могут перекрываться: коллизий ещё нет, порядок слоёв остаётся общим.
- Новый враг влияет на прежние длинные сценарии боя: изолировать прежние тесты одной цели при необходимости, сохранив отдельную интеграционную проверку нового мира.
- Герой может погибнуть от любого врага: немедленно очистить оба вражеских цикла и ввод героя.

## Migration Plan

Зависимости и формат хранения не меняются. Проверить симуляцию, полный браузерный набор и локальную игру; откат убирает нового актёра и поле скорости, сохраняя остальные значения настроек.
