# Design

## Context

См. предложение. Цикл героя адресует цель по ID, преследователи используют общие фазы атаки. Симуляция уже приостанавливается меню и событиями фокуса.

## Goals / Non-Goals

**Goals:** продолжать выбранную команду без удержания мыши, реагировать на урон в покое и создавать несколько противников.

**Non-Goals:** автоматический выбор следующей цели после смерти, препятствия, удаление останков по таймеру.

## Decisions

- `autoContinueAttack` и `autoRetaliate` по умолчанию false для сохранения прежнего управления. Команда фиксирует автоматическое повторение, которое действует независимо от отпускания; клик по земле, меню, потеря фокуса, смерть цели или героя очищают команду. Ответ на полученный удар выбирает атакующего только в покое без текущей атаки и команды движения; он не меняет выбранную цель и не перехватывает ручное управление. При отключённом продолжении ответ наносит один удар.
- Существующие `enemy`, `skeleton` и `pursuer` сохраняются. Новые враги находятся в `spawnedEnemies`, используют уникальные ID и то же преследование. Общие списки выбора, отрисовки, жизни и боя включают массив.
- Спавнеры привязаны к текущей видимой области камеры, а не фиксированной точке мира. Стороны идут по кругу: верх, право, низ, лево; положение вдоль края меняется детерминированно. Отступ 96 мировых единиц оставляет портрет с кольцом за экраном при допустимых масштабах.
- `spawnersEnabled=true`, `spawnInterval=6` секунд (0,5–60), `maxEnemies=8` (0–50, целое). Лимит считает живых боевых врагов, включая два исходных скелета, исключая мишень и останки. Уменьшение лимита не удаляет существующих врагов. Первый спавн происходит после полного интервала. В заполненном мире таймер не копит очередь; после освобождения места создаётся максимум один враг. При отключении таймер очищается. Смерть героя прекращает спавн; reset очищает созданных врагов, ID, сторону и таймер.
- Все новые настройки используют схему с boolean и целочисленной валидацией. Ключ интерфейса v2 однократно сбрасывает прежнее раскрытие, игровые параметры остаются в прежнем ключе. Все шесть разделов закрыты по умолчанию; новые предпочтения раскрытия сохраняются.

## Risks / Trade-offs

Подход использует тот же допуск позиции 0,00001 мировой единицы, что и достижение цели движения. Погрешность вычисления длины диагонального вектора не должна повторно создавать уже достигнутую точку и блокировать начало замаха. Буфер остановки в 2 единицы остаётся внутри дистанции атаки; правила попадания не меняются.

- Ответ на удар мог бы прервать уход игрока: реакция ограничена покоем, выбранная атака сохраняется.
- Останки накапливаются: сохраняются до reset по существующим правилам, лимит ограничивает живых врагов.
- Новый противник может менять прежние тестовые сценарии: тесты одной цели изолируют создание новых врагов при необходимости.
