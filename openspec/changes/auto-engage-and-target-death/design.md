# Design

## Context

См. proposal.md. Симуляция использует фиксированный шаг 120 Гц и одну мишень. Явный выбор цели уже запускает подход, замах, удар и восстановление. Ввод удержания обновляет мировую точку с учётом камеры на каждом шаге. Проверка попадания по портрету сейчас не исключает HP=0. Все объекты проходимы; препятствий и поиска пути нет.

Меню уже скрывается, но открывается при каждом запуске. Три группы сейчас обычные section; схема параметров содержит только числа. Проверки явно ожидают продолжающиеся удары по нулевому HP, поэтому их нужно заменить, а не сохранить.

## Goals / Non-Goals

**Goals:** сохранить один цикл фаз для ручного и автоматического выбора; разделить симуляцию смерти и её отображение; сохранить старые параметры без миграции чисел.

**Non-Goals:** коллизии живых объектов, поиск пути, генерация врагов, самостоятельные атаки без удержания ЛКМ. Поскольку мишень одна, выбор ближайшей цели совпадает с выбором единственной живой мишени.

## Decisions

- Режим `autoAttackMode` — строковое перечисление `off`, `hover`, `nearby`, default `hover`. Выбор в группе «Атака» заменяет булевый переключатель. Значения валидируются по списку; числа остаются без изменений. Альтернатива с кодами 0/1/2 менее понятна при сохранении и диагностике.
- Захват проверяется внутри фиксированного шага после наступления следования, перед обновлением боя. `hover` использует существующее преобразование экранных координат; `nearby` проверяет расстояние между центрами против дистанции атаки. Обе ветки передают управление единой процедуре выбора. После захвата цель сохраняется даже при уходе курсора — это продолжает текущую механику явного выбора.
- HP=0 является источником истины для недоступности. Отдельный таймер смерти начинает отсчёт один раз при смертельном попадании. След текущего удара и восстановление завершаются, повтор и выбор сразу сбрасываются. После восстановления удержание возвращается к следованию; отпущенная кнопка оставляет героя стоять. Смерть не сбрасывает чередование сторон или счётчик атак.
- `deathDuration` по умолчанию 0,2 с, диапазон 0,05–1 с. Прогресс определяет плавный масштаб от 1 до 0,9; grayscale применяется сразу к портрету и его рамке через локальный save/restore Canvas. Кольцо и подсветка выбора не рисуются при смерти. Радиус живого портрета не меняется.
- Мишень — локальный SVG с концентрическими кругами. Кольцо здоровья повторяет геометрию героя: радиус 32, толщина 3, дуга от верхней точки. Числовое HP можно оставить под названием для измерений; горизонтальная полоса удаляется.
- Группы становятся нативными details/summary. Отдельный ключ хранилища сохраняет видимость панели и открытые разделы; ошибки хранилища не блокируют UI. Старый ключ игровых параметров сохраняется. Сброс игровых параметров не сбрасывает разделы. Начальный скрытый UI не вызывает отмену ввода после инициализации.

### Следующий эксперимент: препятствия

Сначала круг героя и несколько статических круглых препятствий. При касании убрать только составляющую скорости, направленную внутрь препятствия, сохраняя скольжение вдоль края. Отдельно проверить быстрые движения на проскок препятствий, касательные контакты и узкие проходы. Живые враги можно позже сделать отдельным переключаемым видом препятствия; останки всегда проходимы.

На первом этапе заблокированный автоподход останавливается с понятной индикацией без дрожания и бесконечных попыток. Автоматический поиск обхода — следующий опыт после проверки самих столкновений. Искусственные границы мира не нужны. Эти предложения не добавляют задачи реализации препятствий в текущее изменение.

## Risks / Trade-offs

- Камера может подвести мишень под неподвижный курсор: захват намеренный; проверить при нескольких масштабах.
- В режиме сближения атака перехватывает движение рядом с целью: режим явно выбирается в меню и легко отключается.
- Возобновление движения после убийства может выглядеть неожиданно: сохранить полный цикл восстановления и проверить удержание и отпускание отдельно.
- Canvas-фильтр может затронуть героя: ограничить filter сохранением и восстановлением контекста, проверить изображение обоих объектов.

## Migration Plan

Базовые спецификации готового movement-and-combat синхронизируются перед созданием дельт. Новые поля параметров имеют defaults; старые JSON продолжают загружаться. Обновить устаревшие проверки HP=0 и открытого при старте меню, выполнить полный набор проверок и визуально проверить живую/мёртвую мишень. Откат к прежнему поведению автозахвата доступен через «Выкл»; смерть остаётся новым правилом.
