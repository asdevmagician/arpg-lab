# Proposal

## Why

Нужен минимальный локальный прототип ARPG для проверки управления мышью и игрового цикла. Первый этап изолирует перемещение и камеру, чтобы дальнейшие механики проверялись по отдельности.

## What Changes

- Локальная браузерная игра с круглым портретом героя и кольцом полного здоровья.
- Клик ЛКМ задаёт точку мира; удержание ведёт героя за курсором; отпускание завершает движение к последней цели.
- Камера удерживает героя в центре, бесконечная подложка позволяет видеть перемещение.
- Автоматические проверки движения, ввода, камеры и независимости скорости от частоты кадров.
- Инструкции локального запуска и короткого ручного эргономического теста.

## Capabilities

### New Capabilities

- `movement-loop`: перемещение мышью, игровой цикл, камера, бесконечная подложка и безопасная обработка потери фокуса.

### Modified Capabilities

Нет.

## Impact

Новый проект на HTML, CSS и JavaScript с Canvas 2D. Node.js нужен для локального сервера и тестов; браузерный код не использует внешних библиотек или сети. Боевые механики, противники и оружие остаются за пределами этапа.
