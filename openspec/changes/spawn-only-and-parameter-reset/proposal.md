# Proposal

## Why

Два начальных врага мешают экспериментировать с управляемым потоком спавна. Для сравнения параметров нужен быстрый возврат отдельного значения без сброса остальных настроек.

## What Changes

- Убрать неподвижного скелета и начального преследователя; оставить мишень и спавнеры с четырёх сторон.
- Считать лимит только по живым скелетам из спавнеров. Возврат в начало очищает их и перезапускает таймер.
- Добавить рядом с каждым параметром кнопку индивидуального сброса с сохранением результата.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `combat-loop`: начальная популяция врагов и сброс мира.
- `experiment-settings`: индивидуальный сброс любого параметра.

## Impact

Симуляция, отрисовка, меню и стили, тесты и README. Новых зависимостей нет. Сохранённые параметры совместимы.
