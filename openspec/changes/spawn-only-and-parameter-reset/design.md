# Design

## Context

Симуляция хранит двух начальных врагов отдельно от массива спавна. Меню строится по PARAM_SCHEMA и уже имеет общий сброс. Мотивация описана в proposal.md.

## Goals / Non-Goals

Единый источник атакующих врагов и единая обработка сброса параметров всех типов. Настройки спавна и сохранения остаются совместимыми.

## Decisions

- Удалить начальные объекты из состояния и отрисовки, использовать только spawnedEnemies. Общая фабрика скелета сохраняет существующую механику и позволяет задавать тестовые сцены без устаревших полей.
- Кнопки строить из той же схемы параметров, значения брать из DEFAULT_PARAMS. Повторять константы вручную в меню не нужно.
- Индивидуальный сброс проходит через updateParameters, синхронизацию контролов, onChange и сохранение, как общий сброс. Название группы различает одинаковые подписи параметров.

## Risks / Trade-offs

Тесты прежних стартовых врагов → заменить явными сценами со скелетами и браузерными проверками настоящего спавна. Мишень сохраняется как учебный объект и не входит в лимит.
