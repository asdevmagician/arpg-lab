## ADDED Requirements

### Requirement: Индивидуальный сброс параметра
Возле каждого параметра SHALL находиться доступная с клавиатуры кнопка сброса с понятным названием. Нажатие SHALL возвращать только выбранный параметр к значению по умолчанию, синхронизировать его элементы управления, применять и сохранять результат. Остальные значения и состояние разделов SHALL сохраняться. Общий сброс SHALL оставаться доступным.

#### Scenario: Числовое значение
- **WHEN** пользователь сбрасывает изменённую максимальную скорость
- **THEN** поле и ползунок показывают значение по умолчанию, другие параметры не меняются, результат сохраняется после перезагрузки

#### Scenario: Выбор и переключатель
- **WHEN** пользователь сбрасывает режим автоперехода или переключатель спавнеров
- **THEN** выбранный элемент получает значение по умолчанию, остальные настройки и свёрнутость разделов сохраняются
