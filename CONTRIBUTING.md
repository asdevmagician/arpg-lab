# Работа с проектом

Проект исследует управление и базовый игровой цикл минимальной ARPG. Сохранять локальный запуск, простые портреты и наблюдаемые механики.

1. Начать независимый эксперимент в ветке `experiment/<гипотеза>` от `v0.1.0`.
2. Описать гипотезу и критерий проверки. Поведенческие изменения оформить в OpenSpec.
3. Новые показатели вынести в общее меню параметров с индивидуальным сбросом.
4. Проверить симуляцию и затронутые браузерные сценарии; перед объединением выполнить `npm test`.
5. Обновить README и нужные документы, записать результат эксперимента.
6. Делать коммиты с конкретным описанием изменения. Объединять полезные изменения через pull request.

Подготовка среды и работа с несколькими вариантами описаны в [development.md](docs/development.md). О проблеме сообщать с воспроизводимыми шагами, параметрами, браузером и исходным commit. Для ошибок атаки указать режим захвата, автопродолжение, HP героя и состояние команды.
